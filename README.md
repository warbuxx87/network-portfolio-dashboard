> A dashboard and reporting interface for the Alkemi Network

### 🏠 [Homepage](https://alkemi.fund)

## Install

```sh
npm install
```

## Usage

```sh
node ,/bin/www
```

## Run tests

```sh
npm test
```

## Build with Docker

```sh
docker build -t alkemi-fund .
docker run -p 8080:3000 alkemi-fund
```
